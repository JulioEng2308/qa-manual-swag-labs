# Swag Labs — Manual QA Portfolio

Manual testing portfolio project covering selected scenarios
in the Swag Labs demo application.

## Author
Julio Cesar Cerrate Castro

## Project Objective
Practice and demonstrate manual QA skills through test design,
execution, evidence collection, and test reporting.

## Application Under Test
https://www.saucedemo.com/

## Tested Scenarios
- Login with valid credentials.
- Login with an incorrect password.
- Login with both fields empty.
- Adding a product to the cart.
- Removing a product from the cart.
- Completing a simulated purchase.

## Test Results

| Executed | Passed | Failed | Blocked |
|---|---|---|---|
| 6 | 6 | 0 | 0 |

These results apply only to the documented scenarios
and recorded execution environment.

## Skills Practiced
- Defining test scope.
- Designing positive and negative test cases.
- Documenting preconditions, test data, and expected results.
- Executing manual functional tests.
- Comparing actual and expected results.
- Collecting screenshot evidence.
- Reporting results and testing limitations.

## How to Review This Project
1. Read the test scope.
2. Review the test cases and their execution records.
3. Open the linked screenshots.
4. Read the execution report for findings and limitations.

## Limitations
This initial cycle covers six selected scenarios.
It does not cover every application feature or input combination.
See the test execution report for detailed limitations.
